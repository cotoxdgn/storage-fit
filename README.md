# 収納ぴったり検索

収納スペースの内寸（幅・奥行・高さ）を入れると、ぴったり収まるボックス型収納（無印良品・IKEA）を、充填率の高い順に表示するWebアプリです。

- 公開URL: https://cotoxdgn.github.io/storage-fit/
- iPhone・iPad・PCで使えます。ホーム画面に追加すると、全画面で開けます。
- 検索条件はURLに入ります。ブックマークすると、同じ結果を再表示できます。
- 商品データ（`products.json` / `products.js`）は、各社公式サイトに掲載された外寸を2026-10-30に確認したものです。廃番・仕様変更・価格改定がありえるため、発注前に商品ページで確認してください。
